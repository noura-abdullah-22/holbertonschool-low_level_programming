# C - Functions, nested loops

This project covers functions in C: declaring prototypes, defining and calling functions, header files (`main.h`), variable scope, nested loops, and printing with `_putchar`.

## Tasks

| File | Description |
|------|-------------|
| `main.h` | Header file with the prototypes of all functions |
| `0-putchar.c` | Prints `_putchar` followed by a new line |
