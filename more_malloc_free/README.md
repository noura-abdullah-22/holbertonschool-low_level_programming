# C - More malloc, free

This project covers more dynamic memory allocation in C, using malloc, free and exit.

| File | Description |
|------|-------------|
| `0-malloc_checked.c` | Function that allocates memory using malloc, exiting with status 98 on failure |
| `1-string_nconcat.c` | Function that concatenates s1 and the first n bytes of s2 into newly allocated memory |
| `2-calloc.c` | Function that allocates memory for an array and sets it to zero, using malloc |
