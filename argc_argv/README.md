# C - argc, argv

This project covers how to use command line arguments in C with argc and argv.

## Files

| File | Description |
|------|-------------|
| main.h | Header file with all prototypes |
| 0-whatsmyname.c | Prints the program name |
| 1-args.c | Prints the number of arguments passed to the program |
| 2-args.c | Prints all arguments it receives, one per line |
| 3-mul.c | Multiplies two numbers |
