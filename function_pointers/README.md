# C - Function pointers

This project covers function pointers in C: what they are, what they hold, and how to use them.

## Files

| File | Description |
|------|-------------|
| function_pointers.h | Header file with all prototypes |
| 0-print_name.c | Prints a name using a function pointer |
| 1-array_iterator.c | Executes a function on each element of an array |
| 2-int_index.c | Searches for an integer using a compare function |
| 3-calc.h, 3-op_functions.c, 3-get_op_func.c, 3-main.c | Simple calculator using function pointers |
