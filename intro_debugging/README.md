# Intro to Debugging

This project practices debugging C programs by tracing execution step by step with Python Tutor, then fixing logic errors such as off-by-one loops, wrong loop variables, values that are never reset, and incorrect return values.

## Tasks

| File | Description |
|------|-------------|
| `sum_to_n.c` | Fixed a loop condition and return value so the function returns the sum from 1 to n |
| `multiplication_table.c` | Removed an extra increment of the inner loop variable so every product is printed |
