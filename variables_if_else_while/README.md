# C - Variables, if, else, while

This project covers the basics of C: declaring and assigning variables (`char`, `int`, `unsigned int`), arithmetic, relational and logical operators, `if` / `else` statements, `while` loops, printing with `printf`, and the ASCII character set.

## Tasks

| File                      | Description                                 |
|---------------------------|---------------------------------------------|
|`0-positive_or_negative.c` | Prints whether a random number is positive, zero or negative             |
----------------------------|---------------------------------------------|
| `1-last_digit.c`          | Prints the last digit of a random number and whether it is greater than 5, 0, or less than 6 and not 0                 ||---------------------------|---------------------------------------------|
